# Style · Citation

> Layer 2 — universal presentation convention. No project specifics.

How to attribute claims and sources.

## Code references
- Cite as `path:line` (or `path:start-end` for a span) so it's clickable.
- Quote the minimal relevant snippet, not the whole region.

## External sources
- Attribute each carried-forward claim to its source: title + URL (+ date when
  recency matters).
- Distinguish what the source says from your synthesis of it.

## Factual claims
- A non-obvious factual claim should be traceable to where it came from.
- If a claim is from memory and unverified, mark it as such rather than dressing it
  as sourced.

## Quotations
- Quote exactly; use ellipsis for elision; don't alter meaning by trimming context.

## Don'ts
- Don't cite a source you didn't actually consult.
- Don't paraphrase a source into a stronger or broader claim than it makes.
- Don't strip provenance when moving a claim from research into a final answer.
