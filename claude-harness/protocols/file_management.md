# Protocol · File Management

> Layer 1 — universal per-task procedure. No project specifics.

Use when creating, editing, moving, or deleting files.

## Before you change a file
1. **Read it first.** Never edit or overwrite a file you haven't opened in this
   session.
2. **Check the gates.** Respect the active project's `constraints.md`
   (`allow_file_creation`, `allow_file_deletion`, `require_plan_before_edit`). If a
   gate forbids the action, stop and surface it.

## Editing
- Prefer the smallest precise edit over rewriting a whole file.
- Preserve surrounding style, formatting, and conventions.

## Creating
- Create a new file only when an existing one won't do. Put it where the project's
  conventions say it goes.
- Don't scatter scratch files; clean up throwaways.

## Deleting / overwriting
- Look at the target first. If its actual content contradicts how it was described,
  or you didn't create it, **surface that instead of proceeding**.
- Deletion and overwrite are hard to reverse — confirm unless explicitly authorized.

## Don'ts
- Don't overwrite an unread file.
- Don't delete on assumption about what a file contains.
- Don't create files the task didn't call for.
