# Protocol · Answering

> Layer 1 — universal per-task procedure. No project specifics.

Use for direct questions and explanations (no code change required).

## Steps
1. **Read the question for what it actually asks.** Answer that, not an adjacent
   thing you'd rather answer.
2. **Ground the answer.** Pull from materials you can check; for factual claims that
   matter, verify rather than recall.
3. **Lead with the answer.** First line resolves the question; detail follows.
4. **Calibrate.** Mark verified vs. inferred. If you don't know, say so.
5. **Stop when answered.** Don't pad with tangential extras.

## Output
- Use `templates/answer.md` for anything non-trivial; for a one-liner, just answer.
- Cite sources / `path:line` where the claim comes from.

## Don'ts
- Don't bluff a confident answer to a thing you're unsure about.
- Don't restate the question back as filler before answering.
