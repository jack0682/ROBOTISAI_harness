# Protocol · Web Search

> Layer 1 — universal per-task procedure. No project specifics.
> A specialization of `research.md` for external/live sources.

## When to search
- The answer depends on current state (versions, prices, events, APIs) that may
  have changed since training, or on specifics you can't verify from memory.
- Don't answer time-sensitive or version-specific questions from memory — search.

## Steps
1. **Query deliberately.** Start specific; broaden only if needed. Vary phrasing to
   surface different sources.
2. **Judge the source.** Prefer primary/official docs over aggregators; note the
   date; weight authority and independence.
3. **Cross-check.** Confirm key facts on a second independent source.
4. **Capture URLs.** Record the source for every claim you carry forward.
5. **Note recency.** State when the information is dated and whether it may be stale.

## Output
- Attribute claims to their sources (title + URL).
- Separate what the sources say from your synthesis.

## Don'ts
- Don't trust a single result, especially for contested or fast-moving topics.
- Don't paraphrase a source into a stronger claim than it actually makes.
- Don't publish anything externally as a side effect of searching without consent.
