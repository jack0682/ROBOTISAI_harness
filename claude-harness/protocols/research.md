# Protocol · Research

> Layer 1 — universal per-task procedure. No project specifics.

Use when gathering and synthesizing information (internal or external).

## Steps
1. **Sharpen the question.** Know precisely what you're trying to learn and what a
   good-enough answer looks like. Narrow an underspecified question first.
2. **Plan the sweep.** Decide the angles/sources worth checking. Different angles
   find different things — don't rely on one.
3. **Collect with provenance.** For each finding, record where it came from. No
   claim without a traceable source.
4. **Triangulate.** Corroborate important claims across independent sources.
   Note conflicts rather than silently picking one.
5. **Verify adversarially.** For load-bearing claims, actively try to disprove them
   before accepting.
6. **Synthesize.** Answer the question; separate what's well-supported from what's
   thin; flag the gaps.

## Output
- Use `templates/research_report.md`.
- Cite every non-obvious claim. Mark confidence per finding.

## Don'ts
- Don't present a single source as consensus.
- Don't fill a gap with a plausible guess — name the gap.
- Don't let recency or confident phrasing substitute for reliability.
